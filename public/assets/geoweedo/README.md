# GeoWeedo branding

This folder is the single source of truth for GeoWeedo website branding.

## Primary live asset

`geoweedo-mascot.png`

The site header, homepage play card, mobile Search/Play splash, manifest, favicon metadata, Apple icon metadata, and Open Graph metadata all reference this file.

To update the mascot everywhere, replace `geoweedo-mascot.png` in this folder and deploy.

Tagline: **WEEDO SEARCH. WEEDO FIND. WEEDO PLAY.**

Keep future logo, icon, social, hero, and branding image files in this folder rather than scattering them through `app/` or other directories.
